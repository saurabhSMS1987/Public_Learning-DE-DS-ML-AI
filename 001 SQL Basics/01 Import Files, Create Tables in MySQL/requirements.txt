# Requirements: MySQL for Audit Data (Importing Files & Creating Tables)
#
# These lessons are SQL-only, so there are no Python packages to install.
# This file lists the software needed to follow them.
# (Running "pip install -r requirements.txt" is safe: every line is a comment.)

# --- Database ---
# MySQL Server 8.0.19 or later
#   - 8.0.16+ enforces CHECK constraints (Lesson 1)
#   - 8.0.19+ supports "INSERT ... AS new ON DUPLICATE KEY UPDATE" (Lesson 3)
#   - Download: https://dev.mysql.com/downloads/mysql/

# --- Client ---
# MySQL Workbench 8.0 or later
#   - Table Data Import / Export Wizards (Lessons 2, 9)
#   - Data Export / Import for backups (Lesson 9)
#   - Download: https://dev.mysql.com/downloads/workbench/

# --- Spreadsheet ---
# Microsoft Excel (or any tool that saves "CSV UTF-8")
#   - Preparing source files (Lesson 2) and opening exports (Lesson 9)

# --- Optional ---
# mysqldump (installed with MySQL Server) for command-line backups (Lesson 9)
# A text editor (VS Code, Notepad++) for editing CSVs without Excel reformatting them

# --- Server settings used in some lessons ---
# local_infile = ON     (Lessons 7, 8: SET GLOBAL local_infile = 1;)
# secure_file_priv      (Lessons 7, 9: SHOW VARIABLES LIKE 'secure_file_priv';)
